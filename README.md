One kind, funny fortune for the houseplant on the windowsill, written for make.fun's "Fortune in a Pot" bounty ($2, 1st place only). A gardener judge compares fortunes two at a time and keeps the one that lands better.

The fortune:

> This week someone will water you right on time, and you will forgive them for every dry Tuesday on this windowsill.

## Run it

```sh
python3 main.py
```

It writes the fortune to `/output/entry.txt` and prints it. Deterministic: the same single line, 115 characters, on every run.
